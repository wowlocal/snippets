Подтверждённые положительные результаты следующего цикла:

- 110 тестов общего ядра: account binding, конфликтные копии, зависимости конфликтов.
- Смена аккаунта при задержанном ответе прошла на macOS, iPhone, iPad, Android и Linux. Новый аккаунт остался пустым.
- На каждой из пяти платформ процесс завершён после принятого сервером изменения; сразу после восстановления собственная правка сохранилась, число записей осталось 3. Последующий обмен выявил P2 из списка выше.

Использованы симуляторы iPhone/iPad, отдельный Android AVD и Arch в UTM. Проверки не доказывают поведение физических устройств или Production CloudKit.

## Артефакты

Санитизированные агрегаты лежат в `evidence/`. Полные логи, xcresult и снимки синтетических библиотек — `/tmp/snippets-account-key-chaos/`. Каталог `/tmp` может быть очищен системой. Не публиковать весь каталог: отдельные приватные fixtures содержат тестовые bearer credentials; после работы их семейства отзываются.
